# @agentkernel/pi-agent

Prism capability package for users who want to use Pi Agent directly.

This package will provide:

- Prism domain skills
- Prism tools extension
- Prism permission gates
- Prism prompt templates

Planned install command after publishing:

```bash
pi install npm:@agentkernel/pi-agent
```

Local development install will be documented after the first extension is implemented.
